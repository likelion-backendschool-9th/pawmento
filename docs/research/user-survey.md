# 첫 사용자 설문

질문형 일기가 기록 부담을 줄이는지 확인하는 구글폼 설문이다. 폼은 이 문서를 보고 그대로 만든다. 이슈: [#139](https://github.com/likelion-backendschool-9th/pawmento/issues/139)

## 확인할 가설

| 가설 | 확인하는 문항 |
| --- | --- |
| 기록이 끊기는 주된 이유는 무엇을 쓸지 떠오르지 않아서다 | A5, A6 |
| 질문이 있으면 기록하기 쉬워진다 | A9, A10 |
| 사진만으로는 남지 않는 것(소리, 습관, 에피소드)을 남기고 싶어 한다 | A7 |
| 반려동물 기록을 가족과 함께 남기거나 나눈다 ([가족 공통 질문](../question/README.md)의 전제) | A8 |
| 이별 뒤 기억을 다시 보는 시점은 사람과 시기에 따라 달라서 보호자가 직접 골라야 한다 (기억의 정원 원칙) | B2, B3 |

## 정한 것

- **목적**: 첫 회차는 질문형 일기를 확인하는 데 집중한다. 이별 경험은 답할 의향이 있다고 고른 사람에게만 같은 폼 안에서 묻는다. 대상을 찾기 어렵고 조심스럽게 다가가야 하는 주제라, 따로 폼을 보내지 않고 응답자가 고르게 한다.
- **대상**: 지인 중 반려동물과 함께 지낸 사람에게 부탁하고, 그 사람에게 다른 사람을 소개받아 넓힌다. 한 다리 건넌 사람이면 친분 때문에 생기는 편향이 줄어든다.
- **규모와 기간**: 2주 동안 15~20명에게 받는다. 통계가 아니라 패턴을 찾는 용도다.
- **익명**: 이름과 연락처를 받지 않는다. 지인 관계에서는 이름이 붙으면 답이 조심스러워진다. 깊은 이야기는 지인에게 따로 인터뷰를 요청해 듣고, 폼 결과를 본 뒤 별도 질문으로 진행한다.
- **분량**: 5~7분 안에 끝나게 한다. 섹션 A는 10문항에 서술형 2개, 섹션 B는 4문항이다.
- **화면 이미지**: 섹션 A의 기록 습관 질문을 모두 마친 뒤 A9에서 보여준다. 앞쪽 답이 이미지에 끌려가지 않게 하기 위해서다. 홈 화면 전체가 아니라 "오늘의 질문" 카드만 보여준다.
- **보상**: 지금은 주지 않는다. 나중에 다시 정한다.
- **결과 정리**: 원본 응답은 구글 시트에 두고 저장소에 올리지 않는다. 요약은 이 문서의 [결과](#결과)에 적는다.

## 폼 흐름

```text
시작 안내 → Q0
  ├ 지금 함께 지내요      → 섹션 A → 의향 질문
  ├ 예전에 함께 지냈어요  → 의향 질문
  └ 함께 지낸 적 없어요   → 종료

의향 질문
  ├ 네, 답할게요            → 섹션 B → 종료
  ├ 떠나보낸 경험이 없어요  → 종료
  └ 답하고 싶지 않아요      → 종료
```

구글폼에서는 섹션을 나누고, 선택형 문항의 "답변을 기준으로 섹션으로 이동" 설정으로 갈래를 만든다. 모든 문항은 필수 응답이 아니다. 갈래를 정하는 Q0와 의향 질문만 필수로 둔다.

## 문항

### 시작 안내

> **반려동물 기록에 대한 짧은 설문 (5분)**
> 반려동물과의 일상을 기록하는 서비스를 준비하고 있어요. 이름이나 연락처는 받지 않고, 답하기 어려운 질문은 건너뛰셔도 괜찮아요.

| # | 질문 | 형식 | 선택지 |
| --- | --- | --- | --- |
| Q0 | 반려동물과 함께 지낸 경험이 있나요? | 객관식 (필수) | 지금 함께 지내고 있어요 → 섹션 A / 예전에 함께 지냈고, 지금은 아니에요 → 의향 질문 / 함께 지낸 적이 없어요 → 종료 |

| A3 | 반려동물 사진·영상은 주로 어디에 모아두나요? | 체크박스 | 휴대폰 사진첩 / 클라우드 / SNS / 가족 단톡방 / 기록 앱 / 기타 |
| A4 | 최근 한 달 동안 사진 말고 글이나 메모로 남긴 적이 있나요? | 객관식 | 자주 / 가끔 / 거의 없음 / 없음 |
| A5 | 기록 앱이나 일기를 쓰다가 그만둔 적이 있다면, 이유는? | 체크박스 | 귀찮아서 / 쓸 말이 떠오르지 않아서 / 시간이 없어서 / 앱이 불편해서 / 그만둔 적 없음 / 기타 |
| A6 | 최근에 남기고 싶었지만 남기지 못한 순간이 있나요? 무엇 때문이었나요? | 장문형 | |
| A7 | 사진으로는 남지 않아서 아쉬운 것이 있나요? | 체크박스 | 목소리·소리 / 습관·행동 / 함께한 에피소드 / 없음 / 기타 |

### 의향 질문

섹션 A를 마친 사람과 Q0에서 "예전에 함께 지냈다"를 고른 사람 모두 이 질문으로 온다.

| # | 질문 | 형식 | 선택지 |
| --- | --- | --- | --- |
| C0 | 반려동물을 떠나보낸 경험이 있다면, 그 경험에 대해 몇 가지 여쭤봐도 될까요? 모든 문항은 건너뛸 수 있어요. | 객관식 (필수) | 네, 답할게요 → 섹션 B / 떠나보낸 경험이 없어요 → 종료 / 답하고 싶지 않아요 → 종료 |

"경험 없음"과 "답하고 싶지 않음"을 나눈 것은 응답률을 해석할 때 둘을 구분하기 위해서다.

# 반려동물 관리 목록·상세의 출생 연도와 나이 표시

- 관련 이슈: [#253](https://github.com/likelion-backendschool-9th/pawmento/issues/253)
- 서버 계약: [출생 연도와 연도 기준 나이](birth-year-and-age.md) (#178, #197)

## 요구사항

### 기존 생일 칸에 출생 정보를 표시한다 (#253-R1)

서버 반려동물 관리 목록과 상세에서 기존 생일 칸을 재사용한다. 날짜가 있으면 각 화면의 기존 날짜 표기와 ‘생일’ 라벨을 유지한다. 날짜가 없고 연도가 있으면 같은 칸에 ‘출생 연도’와 `2020년`처럼 연도를 표시한다. 서버의 `ageByYear`가 있으면 같은 칸에 `연도 기준 6살`처럼 덧붙인다. 정보가 없으면 기존 `—`를 표시한다.

- #253-S1 정확한 생일 [테스트]
  - Given 서버 목록과 상세 응답에 `birthday: "2020-05-12"`, `birthYear: 2020`, `ageByYear: 6`이 있다.
  - When 보호자가 관리 목록과 상세를 연다.
  - Then 기존 생일 표기와 `연도 기준 6살`을 보며, 별도 출생 연도 항목이 중복 표시되지 않는다.
- #253-S2 연도만 있거나 올해 태어난 경우 [테스트]
  - Given 생일 없이 서버에서 `birthYear: 2020`, `ageByYear: 6`을 반환한다.
  - When 보호자가 관리 목록과 상세를 연다.
  - Then ‘출생 연도’ 라벨, `2020년`, `연도 기준 6살`을 본다. 서버 나이가 0이면 `연도 기준 0살`로 표시한다.
- #253-S3 출생 정보 또는 나이가 없는 경우 [테스트]
  - Given 세 출생 정보 필드가 모두 `null`이다.
  - When 보호자가 관리 목록과 상세를 연다.
  - Then 기존 `—`를 표시한다. 생일이나 연도만 있고 나이가 `null`이면 해당 출생 정보만 표시한다.
- #253-S4 실제 서버 조회와 배치 [직접]
  - Given 서버에 로그인한 보호자에게 정확한 날짜·연도만·미입력 반려동물이 있다.
  - When 데스크톱과 320px 모바일에서 관리 목록·상세를 열고 다시 불러온다.
  - Then 같은 서버 값이 유지되고, 값과 라벨이 승인된 배치로 표시된다. 폭이 좁아도 기존 카드 안에서 줄바꿈이 되며 가로 넘침이나 글자 겹침이 없다.

## 범위 밖

등록·수정 화면의 입력 방식, 쓰기 API, 사진, 가족 목록, 마이페이지, 데모 화면, 공용 CSS 변경.

## 작업 순서

1. 아래 표시안을 확인받고 승인 내용을 기록한다.
2. 기존 서버 관리 응답 매핑에 `birthYear`와 `ageByYear`를 추가하고 날짜·연도·빈 값의 표시 규칙을 관리용 화면에 연결한다.
3. #253-S1~S3을 프론트 테스트로 확인한다. #253-S4는 실제 백엔드·로그인 환경에서 관리 목록과 상세를 데스크톱·모바일로 확인한다.

## 정한 것

- 나이는 서버의 `ageByYear`를 사용하고 브라우저에서 재계산하지 않는다. 서버 나이가 없으면 나이 문구를 생략한다. (#253)
- 기존 카드와 생일 칸을 재사용하고 날짜 포맷을 유지한다. (#253)
- 표시안은 사용자 승인 대기다. 기존 강조 값 줄에는 날짜 또는 출생 연도를 둔다. 아래의 작은 라벨 영역에는 날짜가 있으면 `생일 · 연도 기준 6살`, 연도만 있으면 `출생 연도 · 연도 기준 6살`처럼 표시한다. 한 줄이 좁으면 나이 문구를 라벨 영역 안에서 아래 줄에 둔다. 나이가 없으면 라벨만 표시한다. 기존 카드 폭과 글자 스타일을 사용하며, 승인 후 #253-S4에서 목록과 상세의 배치를 확인한다. (#253)

## 담당과 경계

회의(2026-11-16) 기준 도균 담당 후보:

- 커뮤니티 **신고 관리**
- 우체통 **엽서 판매 관리**

겹치지 않게 둘 것:

- **관리자 계정·역할(권한)** 자체는 계정(member) 담당(다윗)
- **질문 풀 관리** API·화면(`/admin/questions` 등)은 질문 도메인 설계(#30 / #31, 선아). 이 폴더에서 질문 CRUD를 다시 정의하지 않는다.

인증: 로그인·`ADMIN` 역할 검사는 member/security와 맞춘다. 관리자 전용 경로 테스트는 #14-S8이 예고한 대로 경로가 생길 때 요청 전체로 확인한다.

## MVP에서 다룰 후보 (미착수)

- 신고 목록·처리 상태 변경
- 엽서 판매(또는 생성물) 운영 조회 — 우체통/AI 본기능 일정과 맞춤
- (데모에 있는) 공지·회원 상태 등은 범위에 넣을지 후속 이슈에서 정함

## 아직 정하지 않은 것

- 신고·엽서 판매의 데이터 소유 도메인(community / postcard / admin 패키지 여부)
- 관리자 API 경로 prefix와 권한 부여 방식
- 본문 요구사항·시나리오([plan-template](../plan-template.md) 적용)
- 개발 Feat 이슈 번호

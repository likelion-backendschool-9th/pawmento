# 전체 프론트엔드 데모 확장

기준 이슈 #12와 P1 계획을 확장한다. 사용자가 P1~P3 전체 화면·데모 동작을 명시적으로 선택했으며 질문+답변 보존, 원본 이미지의 로고 사용, PC 웹앱 레이아웃을 요청했다.

## 요구사항

- #12-R5 일기는 질문 ID·질문 본문·답변·기억 날짜를 함께 저장한다. 수정 시 원 질문을 보존하며 홈·달력·타임라인·상세에서 질문과 답변을 함께 표시한다.
- #12-R6 원본 코기 이미지는 워드마크와 결합한 로고로 사용한다. PC는 고정 사이드바·넓은 작업 영역·보조 패널을 사용하고 모바일은 별도 단일 열을 사용한다.
- #12-R7 P2 모드 전환, 정원(과거 오늘·무작위 기억), 미디어 모음·영상/음성 첨부, 질문 이력, 커뮤니티 CRUD·댓글·좋아요·검색·분류·신고·내 활동을 브라우저 데모로 연결한다.
- #12-R8 P3 정원 전용 우체통·기록 선택·생성 진행/완료/실패·보관·다운로드, 가족 초대·참여 확인·역할 변경·공유 해제를 데모로 제공한다. 실제 AI·메일 발송·다른 기기 공유로 표시하지 않는다.
- #12-R9 관리자 데모에서 신고 처리·질문 풀·공지·데모 회원 상태를 확인하고 변경한다. 설치 가능 브라우저에서 설치 안내와 오프라인 안내를 제공한다. 자동 푸시는 만들지 않는다.

## 확인 시나리오

- #12-S6 [테스트] 일기 질문 스냅샷·답변이 날짜별 조회와 수정 이후 보존. [직접] 일기 작성→달력→질문과 답변 함께 확인.
- #12-S7 [테스트] 모드 전환과 프로필 수정 후 기록 보존. [직접] 설정 확인→정원→되돌리기, ACTIVE 우체통 미노출.
- #12-S8 [테스트] 게시글·댓글 작성자 제한, 좋아요·신고 중복 방지. [직접] 분류·검색·정렬·글/댓글 CRUD·내 활동.
- #12-S9 [테스트] 원본 기록 참조·생성 상태·실패·재시도·엽서 보관. [직접] 정원→우체통→데모 엽서 생성→상세→다운로드.
- #12-S10 [테스트] 초대 역할·만료·중복 참여 및 역할 변경. [직접] 링크 복사·데모 참여·역할 변경·공유 해제.
- #12-S11 [직접] 사진·영상·음성 선택/재생·갤러리 필터, 자동 재생 없음.
- #12-S12 [직접] 관리자 신고 처리·질문/공지 관리, 설치/오프라인 안내.
- #12-S13 [명령] lint·타입·빌드. [직접] PC 1440/1280, 태블릿768, 모바일390/360px와 모든 메뉴 진입.

## 경계와 저장

기존 workspace 코어는 기록·미디어·모드를 담당한다. 새 life application은 커뮤니티·엽서·가족·운영의 데모 상태를 포트로 읽고 쓰며 브라우저 구현은 outbound에 둔다. 같은 브라우저 안에서만 데모 커뮤니티·초대 상태가 공유되고, 서버 권한·실제 AI 생성·외부 전송은 제공하지 않는다. 실제 파일 업로드는 브라우저 저장 한도 내이며 실패 시 입력을 보존한다.

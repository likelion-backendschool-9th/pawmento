# PawMento 디자인 토큰 · UI 가이드

현재 P1~P3 프론트엔드 데모 기준이다. 실제 값은 [tokens.css](../../frontend/src/shared/ui/tokens.css), 공통 요소는 [globals.css](../../frontend/src/app/globals.css)를 기준으로 한다.

## 일상과 정원

두 공간은 정원의 개방적인 상단 레이아웃을 공유하되 색감·메뉴·본문 요소로 구분한다. 전환은 **설정 → 반려동물별 공간 설정**에서만 제공하며 기록은 유지한다.

| 공간 | PC | 모바일 | 표현 |
|---|---|---|---|
| 일상 · ACTIVE | 상단 로고·가로 탐색·오늘의 질문과 기록 | 전체 메뉴와 일상 전용 하단 탐색 | 연한 녹색, 올리브색 버튼, 간결한 기록 카드 |
| 정원 · GARDEN | 독립된 상단 로고·가로 탐색·사진 전시·우체통 | 정원 전용 하단 탐색과 전체 메뉴 | 크림색 종이, 파스텔 보라, 수채화 정원 |

`AppShell`이 전체 기능 탐색을 구성하고 `SpaceShell`이 두 공간의 공통 레이아웃과 공간별 메뉴를 담당한다. 공통 기능은 정원 전체 메뉴에서도 접근한다. 화면 표현은 어댑터·공유 UI 계층에서 관리하며 도메인·애플리케이션 계층에 넣지 않는다.

## 의미별 색상

`:root`가 일상 기본값이며 `[data-mode="GARDEN"]`에서 정원 값을 상속한다. 공통 요소는 의미별 토큰을 사용한다. 엽서의 종이·우표처럼 개별 표현에 필요한 색은 해당 CSS 모듈에서 관리한다.

| 토큰 | 일상 | 정원 | 용도 |
|---|---|---|---|
| `--surface-page` | `#f6f7f2` | 정원 셸의 수채화 배경 | 캔버스 |
| `--surface-card` | `#fffefb` | `#fffdf8` | 카드 |
| `--surface-elevated` | `#fffefa` | 상속 | 입력·대화상자 기본 표면 |
| `--surface-subtle` | `#edf3e3` | `#eae8f0` | 연한 강조 |
| `--text-primary` | `#39452f` | `#5c5966` | 본문 |
| `--text-secondary` | `#6f7d62` | `#7e7987` | 보조 설명 |
| `--brand-primary` | `#688647` | `#80758e` | 주요 버튼·링크 |
| `--brand-hover` | `#587638` | `#6c627b` | 주요 버튼 호버 |
| `--border-default` | `#dce5ce` | `#ded9dc` | 경계선 |
| `--focus-ring` | `#385e46` | 상속 | 키보드 포커스 |
| `--text-danger` | `#b54745` | 상속 | 오류·삭제 |

정원 공용 카드에는 `--mode-card: #fffdf7e8`, `--mode-subtle: #eeedf4`, `--mode-border: #ded9dc`, `--mode-ink: #5c5966`, `--mode-muted: #7e7987`을 사용한다. 일상에서는 각 컴포넌트의 기본값을 따른다.

## 글꼴과 형태

- 본문은 로컬 Pretendard 가변 글꼴, 브랜드는 Georgia 계열이다. 정원 제목은 Georgia와 본문 글꼴을 함께 지정한다.
- 공통 버튼은 PC 높이 43px·글자 13px, 모바일 높이 42px·글자 12px이다. 버튼·입력 기본 모서리는 8px, 배지는 5px이다.
- 카드·사진·엽서는 용도에 따라 모서리를 지정한다. 초기 시안의 일괄 22~36px 반경과 1200px 레이아웃 제한은 사용하지 않는다.
- 두 공간의 본문 최대 폭은 1360px이다. 1050px 이하에서는 여백을 줄이고 767px 이하에서는 전용 하단 메뉴를 제공한다.
- 공통 마스트헤드는 최대 1380px이다. 일상은 연녹색 아침빛 배경과 오늘 중심의 콘텐츠, 정원은 수채화 배경과 추억 전시를 사용한다. 화면을 휴대전화 프레임 안에 고정하지 않는다.
- 키보드 포커스는 3px 외곽선으로 표시하고 동작 줄이기 설정을 존중한다. 오류·선택 상태는 색과 함께 문구·아이콘으로 전달한다.

## 로고와 이미지

`public/images/04e9e24933b3e4bb.png`는 일상 코기 로고, `8df6278d43d07b9e.png`는 정원 문 로고다. `Brand.tsx`에서 워드마크와 조합하며 페이지 배경에 크게 반복하지 않는다.

`watercolor-garden.png`는 정원·엽서 배경이다. `brand/reference-home.png`는 데모 사진을 잘라 보여주는 실제 소스이므로 불필요한 캡처로 취급하지 않는다.

## 질문 기록과 엽서

질문형 일기는 날짜·질문 식별자·질문 원문·답변을 함께 저장한다. 홈·기록 상세·캘린더에서도 질문과 답변을 함께 표시한다.

엽서는 **기록 한 개를 무작위로 선택하고 그 상황과 반려동물 참조 사진을 바탕으로 새로운 장면을 만드는 경험**을 데모로 표현한다. 현재는 공원·바다·낮잠의 준비된 코기 수채화 이미지이며 실제 AI 생성이나 사용자 사진 분석은 하지 않는다.

앞면은 장면 그림, 뒷면은 줄이 있는 편지·받는 이·보내는 이·우표·소인으로 구성한다. 앞뒤 전환과 다운로드를 제공하며 다운로드 HTML에도 양면·이미지·글꼴을 포함한다.
